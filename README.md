## 四、流量跑完之后会发生什么

这是很多人挑 VPS 时忽略、用起来才后悔的一栏。

DMIT 全部套餐——包括最贵的 CN2 GIA——流量用完之后不停机，自动降到低速继续跑：Pro 和 EB 系列落到 4Mbps 到 10Mbps，T1 系列落到 100Mbps 到 500Mbps。也就是说，你买到的「1TB 月流量」更准确的说法是「1TB 不限速流量」。

这个设计对小站很友好：4Mbps 撑一个日均几百 IP 的 WordPress 站没有压力，撑一个视频源那就是灾难。所以判断标准很简单——你是流量型业务还是请求型业务。请求型（建站、API、跳板）选 Pro/EB 无所谓；流量型（图床、下载、流媒体中转）要么把高速额度买够，要么直接上 T1，那边超量后还有几百 Mbps。

## 八、常见问题

**美国服务器需要备案吗？**
不需要。机器在美国，备案是大陆接入商的要求，跟这个场景无关。

**可以只买一个月试用吗？**
可以。T1.TINY 是 $6.90/月，Pro.TINY 和 EB.TINY 都是 $10.90/月，月付门槛不高。但要注意年付的单月均价通常更低，先月付试线路、满意了再换年付是更稳的路径。

**4Mbps 限速到底能干什么？**
大概相当于一个人看 720P 视频的量。放网站够用，放下载站和大文件分发不够。

**会不会被墙？**
这属于概率问题，任何商家都给不了保证。DMIT 的做法是提供符合条件时的免费换 IP 通道，把可控的部分交给你。选购时把「能不能换 IP」当成一项配置来看，比纠结 IP 段更有意义。

**为什么大家都在抢 AS3，而不是新平台？**
因为同规格价格更低，而且线路是同一套。对绝大多数用途来说，省下的钱比多出来的那点跑分更有价值。
